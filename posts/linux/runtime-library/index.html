程序运行的基本步骤：

  1. 操作系统创建进程，将控制权移交给程序的入口（一般为运行库的某个入口函数）
  2. 入口函数执行初始化
  3. 入口函数负责调用 main 函数执行程序主体
  4. main 执行完毕后，返回入口函数，进行清理工作，通过系统调用结束进程

_start -> __libc_start_main -> main
